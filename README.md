# Three3Pool — 3구 캐럼 당구 시뮬레이터

웹(Three.js)으로 만드는 3구 캐럼 당구 시뮬레이터. 포켓 없는 대, 공 3개(흰·노랑 큐볼 + 빨강).
목표는 **실제에 가까운 물리** — 특히 큐 타격점(영어)이 정확히 반영되는 것.

## 실행 방법

```bash
npm install
npm run dev        # 개발 서버 (http://localhost:5173)
```

서버 없이 실행하려면:

```bash
npm run build      # → dist/index.html 단일 파일 생성
```

빌드 결과물 `dist/index.html`은 JS 전부 인라인된 단일 파일이라 **더블클릭만으로 실행**된다.

## 조작법

| 입력 | 동작 |
|---|---|
| 마우스 좌우 이동 | 조준 (상대 방식 — 커서 위치와 무관하게 각도 회전) |
| Shift + 마우스 이동 / ←→ | 초미세 각도 조정 |
| ↑↓ | 파워 ±3% (Shift = ±1%) |
| 우클릭 드래그 | 타격점(영어) 조절 — 패드 원형 경계 자동 클램프 |
| 휠 / 드래그 | 카메라 줌 / 자유 카메라 회전 |
| 1 / 2 / 3 | 카메라 프리셋 (탑다운 / 큐 뒤 / 자유) |
| Space 또는 버튼 | 발사 |
| R / H | 리셋 / HUD 토글 |
| 흰공·노란공 버튼 | 큐볼 선택 (3구는 양쪽 다 칠 수 있음) |

## 물리 사양 (커스텀 당구 물리)

범용 엔진(cannon-es/Rapier) 대신 당구 특화 물리를 직접 구현했다.

### 타격 모델
- 오프셋 a(수직)·b(수평), UI는 ±0.45R로 클램프(미스큐 영역 제외)
- 효율 η = 1/(1 + m/M + 5(a²+b²)/(2R²)), 공 속도 v = η·V_cue·cosψ (ψ = 큐 상승각)
- 각속도 ω = (b(cosψ·ŷ − sinψ·d̂) − a·ŝ)·5v/(2R²)
- **큐 상승각(0~60°)** 지원: 기울어진 스핀 축이 슬라이딩 중 측면 슬립을 만들어
  실제와 같은 커브(스웨브) 궤적 생성 — 예측선에도 그대로 반영
- 검증: a=+0.4R → 즉시 자연 롤링, 중앙 타격 효율 ≈ 0.72(실제 ~70%), 레벨+영어 → 직선

### 마찰 3단계
- **슬라이딩**: μs=0.2, u̇=−(7/2)μg·û (준해석 적분 — 슬라이드 종료 시점 해석 처리)
- **롤링**: μr=0.01, 수평 ω를 굴림 값(v/R)으로 스냅
- **수직축 스핀 감쇠**: μsp=0.044, 각감속 = 5μsp·g/(2R)

### 충돌
- **볼-볼**: e=0.95, 등질량 법선 교환 + 접선 마찰 throw — jt = min(μBB·jn, m|st|/7), μBB=0.06
- **쿠션**: 노즈 높이 1.25R(중심 위 0.25R), 법선 반발 e=0.85,
  접촉 높이 토크 + 일반화 유효질량 마찰(μ=0.2) → 사이드 스핀 반사각 변화가 자연히 유도됨
- **검출**: 해석적 TOI 이벤트 주도 + 서브스텝 상한 2ms — 터널링 없음
- **결정론**: RNG 미사용, 같은 입력 → 비트 단위 동일 결과

### 궤적 예측
근사식이 아니라 `World.clone()` 후 실제 시뮬을 사전실행(16ms 샘플링, horizon 1.8s).
예측 정확도가 본 시뮬과 완전히 동일하다. 첫 충돌 위치 = 고스트 볼.

## 프로젝트 구조

```
src/
  physics/   constants · ball · collision · world · strike · predict
             ↑ 순수 로직, three Vector3만 사용, DOM/렌더 참조 금지
  render/    scene.ts(렌더러·조명) · table.ts · entities.ts(공·큐스틱·예측선)
  ui/hud.ts  DOM 오버레이 전부
  main.ts    조립 · 루프 · 상태머신(aim ↔ run)
tests/       vitest 물리 검증 9개
```

## 개발

```bash
npm test           # 물리 검증 (머리맞대기/드로우/사이드 스핀/결정론/에너지 단조 등)
npm run build      # tsc --noEmit + vite build
```
